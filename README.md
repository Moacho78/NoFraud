# 🛡️💳 NoFraud

**NoFraud** es una aplicación móvil desarrollada con **React Native + Expo + Firebase** que permite a los usuarios **visualizar y gestionar de manera centralizada sus créditos financieros**, reduciendo el riesgo de fraude y facilitando el control de sus obligaciones con distintas entidades.

La plataforma busca **mejorar la transparencia financiera**, permitiendo al usuario consultar el estado de sus créditos, visualizar detalles relevantes y mantener un seguimiento organizado desde una única interfaz segura.

## 🚀 Características

* 🔐 **Autenticación segura de usuarios**
  Registro e inicio de sesión mediante **Firebase Authentication**.

* 💳 **Consulta centralizada de créditos**
  Permite visualizar todos los créditos del usuario desde distintas entidades financieras en una sola aplicación.

* 📊 **Visualización detallada de créditos**
  Cada crédito muestra información como:

  * Estado del crédito
  * Fecha de apertura
  * Cuota mensual
  * Tasa de interés
  * Monto del préstamo

* 🧾 **Historial de créditos**
  Permite revisar créditos anteriores o finalizados.

* 👤 **Gestión de perfil**
  El usuario puede consultar y actualizar su información personal.

* ☁️ **Almacenamiento en la nube**
  Los datos se almacenan de forma segura en **Firebase Firestore**.

* 📱 **Interfaz intuitiva**
  Diseñada para facilitar la comprensión de la información financiera del usuario.

## ⚙️ Requisitos Previos

Antes de ejecutar el proyecto asegúrate de tener instalado:

* Node.js
* npm
* Expo CLI
* Expo Go en tu celular

Verifica tus versiones:

```bash
node -v
npm -v
```

Descargar Expo Go:

Android
https://play.google.com/store/apps/details?id=host.exp.exponent

iOS
https://apps.apple.com/app/expo-go/id982107779

## 💻 Instalación

### 1️⃣ Clonar el repositorio

```bash
git clone https://github.com/Moacho78/NoFraud.git
cd nofraud
```

---

### 2️⃣ Instalar dependencias

```bash
npm install
```

---

### 3️⃣ Ejecutar la aplicación

```bash
npx expo start
```

---

### 4️⃣ Probar la app

1. Abre **Expo Go** en tu celular
2. Escanea el **QR** que aparece en la terminal
3. La aplicación se cargará automáticamente

⚠️ Asegúrate de que el computador y el celular estén en **la misma red WiFi**.
